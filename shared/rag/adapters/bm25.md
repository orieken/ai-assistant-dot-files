# Adapter: BM25 (Installed Project Docs)

**Corpus**: `project-docs`
**Files**: `<project>/docs/**/*.md` (features, ADRs, KIs, patterns, runbooks)
**Implementation home**: `saturday-mcp` (M1 milestone)

## Rationale

The installed project's `docs/` directory contains prose-heavy structured markdown — feature specs, ADRs,
KIs, patterns, runbooks. BM25 (via SQLite FTS5) is a mature, dependency-free, no-ML lexical ranking
algorithm that excels at this use case:

- **Precision**: structured documents with consistent terminology reward exact keyword matching.
- **No drift**: the index is rebuilt from canonical markdown on demand; no stale embeddings.
- **No operational cost**: SQLite is embedded, no server, no connection management.
- **ADR-001 amplification**: the prescriptive docs structure (consistent headings, DOMAIN_DICTIONARY
  terms in every doc) directly amplifies BM25 retrieval quality.

## Implementation

This adapter is implemented as **MCP tools in `saturday-mcp`** (Milestone 1). Every MCP client
(Claude Code, Cursor, Claude Desktop) gets the same tools.

### MCP Tools

| Tool | Corpus subset | Query type |
|---|---|---|
| `search_docs` | All of `docs/` | BM25 keyword |
| `search_adrs` | `docs/adrs/` | BM25 keyword |
| `search_features` | `docs/features/` | BM25 keyword (semantic variant uses vector adapter) |

### Index Management

- **Storage**: `.claude/rag/docs.db` (SQLite FTS5, gitignored)
- **Initial build**: `install.sh --full` triggers initial indexing
- **Rebuild**: `/reindex` skill (to be added) or `saturday-mcp` tool call
- **Invalidation**: currently manual; future work — file-watcher trigger on `docs/` writes

### Algorithm

1. Open `.claude/rag/docs.db`. If missing, return empty + surface "index not built" warning.
2. Execute FTS5 BM25 query: `SELECT path, title, snippet(docs_fts, -1, '', '', '...', 10) AS excerpt, rank FROM docs_fts WHERE docs_fts MATCH ? ORDER BY rank LIMIT 10`.
3. Map rows to `Reference` objects per the interface contract.
4. Score: normalize FTS5 rank (negative float) to 0.0-1.0 range.
