# Claude Instructions (Saturday Framework)

## Technology Stack
- **Backend / MCP**: Go
- **Frontend**: Vue 3 + Tailwind CSS
- **Test Automation**: TypeScript, Playwright, Cucumber.js, k6

## Error Handling
Use low-cardinality logging with stable message strings:
- `logger.info({id, foo}, 'Msg')`
- `logger.error({error}, 'Msg')`

## E2E Testing (Saturday Framework)
Strictly use `BaseSite`, `BasePage`, `BaseElement`, `BaseFlow`, and `Filters` — never POM.
- Packages: `@orieken/saturday-core`, `@orieken/saturday-cucumber`
- Multi-context: `SiteManager` (cross-app journeys), `TabManager` (multi-tab flows)
- Native OTel for every BDD scenario and Playwright action
- Integrate ML, Heatmaps, and OpenTelemetry as first-class concerns

## API Testing (Sunday Framework)
- `api` fixture with fluent matchers: `toHaveStatus`, `toBeSuccessful`, `toRespondWithin`
- All domain clients extend `BaseApiClient` using `IHttpAdapter`
- Schema validation via Zod (`validateSchema()`)
- Resilience via `CircuitBreaker` / `ExponentialBackoffStrategy` — no custom retry loops
