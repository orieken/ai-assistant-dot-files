# Feature: In-App Chat Between Users

## Problem
Power users have requested the ability to message each other directly within the platform without leaving the app.

## Proposed Solution
Build a real-time chat feature: users can open a chat window with any other user, send text messages, and see delivery/read receipts.

## Scope
- 1:1 messaging only
- Text messages only (no file attachments in v1)
- Delivery receipts (sent/delivered/read)
- Push notifications for new messages (mobile)
- Message history stored indefinitely

## Estimated Effort
8 weeks (2 engineers)
